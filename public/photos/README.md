# Photo drop-ins

Editorial photo slots for the portfolio. Files live here; `src` paths are
wired in `src/data/portfolio.ts`.

| File | Portfolio photo id | Where it appears |
|------|--------------------|------------------|
| `portrait.jpg` | `portrait` | `/scorppu` hero |
| `editorial-home.jpg` | `editorial-home` | Homepage editorial band |
| `editorial-profile.jpg` | `editorial-profile` | `/scorppu` mid-page band |
| `aside-profile.jpg` | `aside-profile` | `/scorppu` beside contact |

`public/profilePics/scorppu.jpg` mirrors the portrait for legacy references.
