# Photo drop-ins

General editorial photo slots (not a graduation gallery). Drop files here,
then set the matching `src` in `src/data/portfolio.ts`.

| Suggested file | Portfolio photo id | Where it appears |
|----------------|--------------------|------------------|
| `editorial-home.jpg` | `editorial-home` | Homepage editorial band |
| `editorial-profile.jpg` | `editorial-profile` | `/scorppu` mid-page band |
| `aside-profile.jpg` | `aside-profile` | `/scorppu` beside contact |

Portrait remains at `/profilePics/scorppu.jpg` unless you change the `portrait` entry.
