# Photo drop-ins

Editorial photo slots for the portfolio. Files live here; `src` paths are
wired in `src/data/portfolio.ts`.

| File | Portfolio photo id | Where it appears |
|------|--------------------|------------------|
| `portrait.jpg` | `portrait` | `/scorppu` hero (work portrait) |
| `about-personal.jpg` | `about-personal` | Homepage about section |
| `editorial-profile.jpg` | `editorial-profile` | `/scorppu` mid-page editorial band |
| `aside-profile.jpg` | `aside-profile` | `/scorppu` beside contact |

`eugene-girlfriend-portrait.jpg` is a named copy of the about-personal photo.
Photos have no captions on the site.
